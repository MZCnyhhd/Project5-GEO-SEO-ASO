# 闪光倒计时落地页部署指南

> 适用对象：运营 / 产品 / 技术
> 适用文件：`landing-page/index.html`（单文件纯静态，零依赖）
> 预计部署耗时：1 ～ 5 分钟

---

## 一、零代码免费部署方案 A：Vercel（推荐，全球 CDN，HTTPS 自动）

### 步骤总览
注册 GitHub → 新建仓库上传文件 → Vercel 导入仓库 → 1 分钟上线

### 详细步骤

#### 第 1 步：注册 GitHub 账号（如有则跳过）
1. 访问 https://github.com/ ，点击右上角「Sign up」
2. 按提示完成邮箱验证、用户名设置
3. 登录后进入个人主页

#### 第 2 步：创建 GitHub 仓库并上传 landing-page 文件
1. 点击 GitHub 右上角 `+` → 选择 `New repository`
2. 填写仓库名称：例如 `shiguang-countdown-landing`（可自定义）
3. 选择 `Public`（公开仓库，免费额度更充足）
4. 勾选 `Add a README file`（可选）
5. 点击 `Create repository`
6. 进入仓库页面后，点击 `Add file` → `Upload files`
7. 将本地 `landing-page` 文件夹内的 `index.html` 直接拖拽上传
8. 拉到底部点击 `Commit changes` 完成上传

> 💡 或者：进入仓库根目录，点击 `Create new file`，文件名填 `index.html`，将本地 HTML 源码全部粘贴进去后保存。

#### 第 3 步：Vercel 注册 & 导入仓库
1. 访问 https://vercel.com/ ，点击右上角「Sign Up」
2. 选择「Continue with GitHub」一键授权登录（推荐）
3. 登录后进入 Vercel 控制台，点击 `Add New...` → `Project`
4. 在「Import Git Repository」区域找到刚才的 `shiguang-countdown-landing` 仓库，点击 `Import`
5. **Project Name**：保持默认或自定义（会影响子域名，例如 `shiguang-countdown-landing.vercel.app`）
6. **Framework Preset**：选择 `Other`（因为是纯静态 HTML）
7. **Root Directory**：保持默认 `./` 即可（如果仓库根目录直接是 index.html）
8. **Build Command**：留空
9. **Output Directory**：留空
10. 点击 `Deploy` 按钮
11. 等待约 30 秒，页面显示 `Congratulations!` 即部署成功

#### 第 4 步：获取公网访问地址
部署完成后，Vercel 会自动分配一个 `xxx.vercel.app` 格式的域名，直接点击访问即可。

## 二、零代码免费部署方案 B：Netlify（Drag & Drop 最快，30 秒上线）

### 步骤总览
注册 Netlify → 拖拽 landing-page 文件夹 → 立即获得公网 URL

### 详细步骤

#### 第 1 步：注册 Netlify 账号
1. 访问 https://www.netlify.com/ ，点击右上角「Sign up」
2. 选择「Sign up with GitHub」或邮箱注册均可
3. 完成邮箱验证后登录

#### 第 2 步：拖拽文件夹上传（核心步骤）
1. 登录后进入 Netlify 控制台首页（https://app.netlify.com/）
2. 找到页面中部显眼的区域：**「Drag and drop your site output folder here」**
3. 将本地电脑上的 **整个 `landing-page` 文件夹**（包含 index.html）直接拖拽到这个区域
4. 等待约 10 ～ 30 秒上传与部署
5. 部署成功后页面会自动跳转，并显示绿色的 `Site deployed` 提示

#### 第 3 步：获取访问链接
页面顶部会自动生成一个随机子域名，例如：`https://serene-torte-12345.netlify.app`，直接点击即可访问。

> 💡 如需自定义子域名：进入 `Site settings` → `Change site name`，修改前缀为 `shiguang-countdown`，最终域名为 `https://shiguang-countdown.netlify.app`。

## 三、零代码免费部署方案 C：GitHub Pages（无需额外注册）

### 步骤总览
创建 GitHub 仓库 → 上传 index.html → Settings 开启 Pages → 等待 2 分钟上线

### 详细步骤

#### 第 1 步：创建 GitHub 仓库并上传文件
参照「方案 A 第 1 ～ 2 步」，创建一个公开仓库并上传 `index.html` 到仓库根目录。

#### 第 2 步：开启 GitHub Pages
1. 进入仓库页面，点击顶部导航栏的 `Settings`（设置）
2. 在左侧菜单找到 `Pages`（位于下方 Code and automation 分组内）
3. **Source** 下拉选项：选择 `Deploy from a branch`
4. **Branch**：选择 `main` 分支（或 `master`，取决于你的默认分支名），右侧目录选择 `/ (root)`
5. 点击 `Save` 保存

#### 第 3 步：等待部署生效
1. 保存后回到 `Pages` 页面，顶部会提示：`Your site is live at https://<你的用户名>.github.io/<仓库名>/`
2. 首次部署需要等待 1 ～ 2 分钟，刷新页面即可看到访问链接从黄色变为绿色
3. 如果显示 `404`，请耐心等待或清理浏览器缓存重试

> 💡 访问链接格式示例：用户名为 `shiguang-team`，仓库名为 `landing`，则最终地址为 `https://shiguang-team.github.io/landing/`

## 四、上线后必做验证步骤（4 步检查清单）

### ✅ 验证步骤 ①：公网 URL 可正常打开
- 在电脑浏览器（Chrome / Edge / Safari）地址栏粘贴部署后的 URL
- 回车访问，确认页面 5 大板块完整显示：
  1. 首屏 Banner 区（金色渐变背景 + 下载按钮）
  2. 核心功能区（5 张卡片）
  3. 使用场景区（4 张场景卡）
  4. 下载引导区（3 个下载大按钮）
  5. FAQ 板块（6 条可展开问答）
- 滚动页面，检查是否有错位、乱码、图片加载失败（本页无外部图片，Emoji 应正常显示）

### ✅ 验证步骤 ②：查看源代码确认 Schema 存在
- 在已打开的落地页页面上，按 `F12` 打开开发者工具（或右键 → 查看网页源代码 / View page source）
- 切换到 `Elements`（元素）标签页，展开 `<head>` 标签
- 确认 **存在 2 个** `<script type="application/ld+json">` 块，且都在 `</head>` 之前、`<body>` 之前
- 快速定位：在源代码中按 `Ctrl+F` 搜索 `"MobileApplication"` 和 `"FAQPage"`，两个关键词都应各命中 1 次

### ✅ 验证步骤 ③：官方 Schema 校验工具验证无报错
1. 打开官方校验工具：https://validator.schema.org/
2. 选择中间的 `FETCH URL` 标签页（不是 Code snippet）
3. 在输入框粘贴你部署后的公网 URL，点击 `RUN TEST`
4. 等待检测完成（约 5 秒），查看结果：
   - **Detected structured data** 下方应显示 2 条记录：
     - 1 条 `MobileApplication` 类型
     - 1 条 `FAQPage` 类型
   - 每条记录展开后，Errors（错误）数量应为 **0**
   - Warnings（警告）如有 1 ～ 2 条（如缺少非必填字段）不影响 SEO，可忽略
5. 将检测结果截图存档，供后续 SEO 优化参考

### ✅ 验证步骤 ④：手机扫码测试下载按钮跳转
1. 用手机微信「扫一扫」或相机扫描页面二维码（或直接用手机浏览器访问 URL）
2. 在手机上依次点击 3 个下载按钮：
   - **iOS 下载** → 应跳转到：`https://apps.apple.com/cn/app/XXXXXXX`（占位链接格式正确即可，后续替换正式 ID）
   - **华为应用市场** → 应跳转到：`https://appgallery.huawei.com/app/XXXXXXX`
   - **官网下载页** → 应跳转到：`https://www.shiguang-countdown.com/download`
3. 即使当前是占位链接，也要确认点击后 **能正常跳转**（不出现 404 / 无法访问 / 请求被拦截 等异常）
4. iOS 设备点击 iOS 按钮、Android 设备点击安卓按钮，确认链接格式正确

> ⚠️ 后续正式上线前，必须将所有占位链接中的 `XXXXXXX` 替换为真实的应用 ID！

## 五、自定义域名绑定指引（如已购买域名）

> 假设已购买域名：`shiguang-countdown.com`（示例，请替换为实际域名）

### 5.1 Vercel 绑定自定义域名
1. 进入 Vercel 控制台 → 进入对应 Project → 点击顶部 `Settings` → 左侧 `Domains`
2. 输入你的域名 `shiguang-countdown.com`，点击 `Add`
3. Vercel 会提示你需要添加的 DNS 记录，按提示操作：
   - 登录你的域名购买平台（阿里云 / 腾讯云 / GoDaddy 等）
   - 进入「域名解析」/ DNS 设置
   - 添加一条 **A 记录**：主机记录 `@`，记录值填 Vercel 提示的 IP（通常是 `76.76.21.21`）
   - 添加一条 **CNAME 记录**：主机记录 `www`，记录值填 `cname.vercel-dns.com`
4. 回到 Vercel 点击 `Refresh`，等待 DNS 生效（通常 5 ～ 30 分钟）
5. 生效后 Vercel 会自动颁发 HTTPS 证书，可通过 `https://shiguang-countdown.com` 安全访问

### 5.2 Netlify 绑定自定义域名
1. 进入 Netlify 对应 Site → `Site settings` → `Domain management` → `Add custom domain`
2. 输入 `shiguang-countdown.com`，按提示完成验证
3. 按 Netlify 提示设置 DNS 解析（推荐使用 Netlify DNS，也可使用外部 DNS）
4. 等待 DNS 生效，HTTPS 证书自动签发

### 5.3 GitHub Pages 绑定自定义域名
1. 在本地 `index.html` 同级目录下，新建一个名为 `CNAME` 的文件（**无扩展名**，全大写）
2. 用记事本打开，文件内容仅一行：`shiguang-countdown.com`（不带 http、不带 www）
3. 将 `CNAME` 文件上传到 GitHub 仓库根目录
4. 到域名购买平台添加 DNS 记录：
   - A 记录 @ → `185.199.108.153`
   - A 记录 @ → `185.199.109.153`
   - A 记录 @ → `185.199.110.153`
   - A 记录 @ → `185.199.111.153`
   - CNAME 记录 www → `<你的用户名>.github.io`
5. 回到 GitHub Pages 设置页面，在 `Custom domain` 输入框填入域名，勾选 `Enforce HTTPS`
